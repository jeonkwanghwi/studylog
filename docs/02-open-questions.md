# 미결 안건 — 브레인스토밍 2부 (완료)

- **상태**: 2026-09-09 전 항목 해소
- **결과 문서**: [구현 스펙](superpowers/specs/2026-09-09-studylog-v1-design.md)

1부에서 제품의 뼈대(인증 단위 · 판정 권한 · 실패 대가 · 아키텍처)를 확정했고,
2부에서 그 뼈대에 붙는 나머지를 정했다. 아래는 각 안건이 어떻게 닫혔는지의 기록이다.

---

## 먼저 확인한 가정 3개

1부에서 임의로 잡았던 가정을 2부 시작 전에 확정했다.

| 가정 | 결과 |
|---|---|
| 1인 1그룹 | **뒤집힘 → 다중 그룹.** 그룹별로 갈리는 것은 피드뿐이고, 목표·streak·패스권·정산은 유저 단위로 남는다. 정산 배치는 그룹 수와 무관하게 유저당 하루 1행 |
| 타임존 KST 고정 | **유지.** 해외 유저는 범위 밖 |
| 세션당 상한 4시간 | **유지. 단 미종료 세션은 0분 `abandoned`로 변경.** 시작 샷 1장으로 4시간이 적립되면 결정 4가 무력화된다 |

## A. 부정행위 방지

**카메라 강제 + 지표 저장만. v1에서 자동 차단은 하지 않는다.**

- 갤러리 선택 차단, 카메라 직접 촬영만 허용
- pHash · EXIF는 컬럼에 계속 쌓지만 차단에 쓰지 않는다 — 임계값을 감으로 정하면 정상 유저를 오차단한다
- 모니터·인쇄물 재촬영 감지는 **판정 프롬프트가 담당**한다. 자동 차단이 없으므로 이것이 유일한 기계적 방어선
- 실질적인 억제력은 **피드 사진 공개에 의한 상호 감시**다 (C 참조)

## B. 결제 상세

| 항목 | 결정 |
|---|---|
| SKU | `pass_3` ₩4,900 / `pass_10` ₩14,000 |
| 복구권 | **별도 상품 없음.** 같은 패스권을 쓰되 사전 방어 1개, 사후 복구 2개를 차감 |
| 영수증 검증 | **RevenueCat** 웹훅. 자체 검증(App Store / Play API 2종)은 무료 티어 초과 시 |
| 환불 | **회수하지 않는다.** 소급 취소는 유저가 이해할 수 없는 사고가 된다. 반복 환불 계정은 수동 차단 |
| 심사 대응 | "패스권은 유저 간 금전 이동이 없는 인앱 소모성 아이템이며, 구매액은 전액 서비스에 귀속된다" |

가격 하한은 단위경제학이 정했다 — **개당 1,000원 미만은 성립하지 않는다.**

## C. 소셜 / 랭킹

- **순위표는 만들지 않는다.** 절대 시간은 직장인이 영원히 꼴찌라 결정 9의 취지가 사라지고, 달성률·streak 기준은 목표를 낮게 잡을수록 유리해서 어뷰징된다. 피드의 streak 배지 비교로 경쟁을 자연 발생시킨다
- **사진은 그룹원에게 전부 공개한다.** A에서 자동 차단을 뺐으므로 상호 감시가 그 자리를 메운다
- 초대는 **딥링크 대신 6자리 코드 수동 입력**. 공유 버튼이 "코드 + 스토어 링크"를 클립보드에 복사한다

## D. 애매 판정 투표 UX

**안건 자체가 소멸했다.** 그룹 투표를 없애고 **유저 설명 + AI 재판정 1회**로 대체했다
(결정 7 변경). 정족수·마감·미투표 기본값·투표 알림이 전부 불필요해졌다.

## E. 알림 설계

| 시점 | 대상 |
|---|---|
| 세션 시작 +3h30m | 해당 유저 — "30분 뒤 자동 폐기" |
| 22:00 | 오늘 목표 미달자만 |
| 판정 fail 즉시 | 해당 유저 |
| 08:00 | 어제 `failed`인 유저만 — streak 복구 유도 |

**친구 인증 알림은 넣지 않는다.** 그룹 5명 × 하루 2세션이면 하루 16통이고 다중 그룹이면 그 배수다.

## F. 판정 프롬프트

- **pass 범위는 넓게.** 종이책·노트북 코딩·태블릿 필기·인강 모두 포함. 게임·예능·SNS·음식·사람 얼굴만 확실한 fail
- **임계는 하나, 관대하게** — `decision == "fail" AND confidence >= 0.7`일 때만 fail, 나머지는 전부 pass. 초기 최대 이탈 원인은 어뷰저가 아니라 "제대로 공부했는데 fail 났다"이다
- 타임아웃 10초, 초과 시 pass
- 출력은 structured output `{ decision, confidence, reason }`, 응답 전문은 `raw_json`에 저장

## G. 온보딩 / 인증

- 로그인은 **Apple + Google 소셜만.** 이메일/비번 없음
- **그룹 0개로 앱을 쓸 수 있다.** 로그인 → 목표 설정 → 바로 인증 시작. 다중 그룹 모델이라 0개가 유효한 상태이고, 이것이 콜드스타트를 푼다
- 목표 시간 변경은 **다음 날부터 적용**된다 (`pending_goal_minutes`). 즉시 반영하면 밤 10시에 10분으로 낮춰 무조건 성공할 수 있다

## H. MVP 범위

**포함** — 소셜 로그인 / 목표 설정 / 그룹 생성·초대코드 참여 / 시작·종료 샷 + AI 판정 /
이의제기 재판정 / 세션 합산 / 04:00 정산 / streak / 그룹 피드 / IAP 패스권 · 자동 차감 · streak 복구 / 푸시 4종

**제외** — 그룹 투표, 순위표, 친구 인증 알림, pHash·EXIF 자동 차단, deferred deep link, 웹, 다국어

**출시 플랫폼: iOS + Android 동시.** 친구 그룹이 단위인 앱은 한 명이 못 들어오면 그 그룹이 통째로 안 굴러간다.

## I. AWS 구성

원래 방향에서 두 가지를 뒤집었다.

| 원래 안 | 변경 | 이유 |
|---|---|---|
| S3 presigned upload | **서버로 직접 업로드** | 유저 1,000명이어도 사진은 분당 3장이다. presigned는 발급 API + 완료 통보 API + 미완료 정리가 따라붙는다 |
| 비동기 판정 파이프라인 | **동기 판정** | 유저는 결과를 즉시 봐야 한다. haiku는 1~3초다. 큐·워커·폴링이 통째로 사라진다 |

나머지 — 서버는 Python + FastAPI, Lightsail t4g.small 단일 인스턴스, RDS `db.t4g.micro`(백업 7일),
정산은 **서버 cron** 04:00 KST(서버리스가 아니므로 EventBridge 불필요), 시크릿은 `.env` 600.

**업로드 시 서버가 긴 변 1280px·q80으로 리사이즈한다.** 장당 2MB → 200KB.
S3 비용을 10배 줄이고 vision 입력 토큰이 함께 줄어 AI 원가에도 직결된다.
